# 🛍️ OutfitWaala - Luxury Clothing Store & Merchant Studio
> **✨ Developed by AJ STUDIO by Aayush Jaiwal ✨**

Yeh ek poori tarah se tayyar, responsive aur aadhunik **Clothing Store (Kapdo Ki Dukaan)** ki website hai jisme **Dukandar khud apne kapdo ke photo aur rate add/edit/delete** kar sakte hain.

---

## 🚀 Website Kaise Chalayein?

1. Kisi bhi server ya setup ki zarurat nahi hai!
2. Apne computer mein `c:\outfitwaala` folder kholein.
3. **Customer Website dekhne ke liye:** `index.html` par double click karein (Google Chrome ya kisi bhi browser mein khul jayegi).
4. **Dukandar Panel kholne ke liye:** `admin\login.html` par click karein.

## ✨ Features (Kya Kya Suvidhayein Hain)

### 👔 1. Dukandar (Shopkeeper) Panel:
- **Kapde Ka Photo Upload:** Computer ya Mobile ki gallery se direct photo chunein ya web link paste karein.
- **Rate & MRP Set Karna:** Apna bechne ka rate (Selling Price) aur MRP daalein taaki customer ko discount dikhe.
- **Rate Badlna (Edit Rate):** Kisi bhi kapde ka rate kabhi bhi "Edit" button dabakar badal sakte hain.
- **Stock Status:** "In Stock" ya "Out of Stock" button par ek click se status change karein.
- **Kapda Hatana (Delete):** Bika hua ya purana maal list se hata dein.
- **Dukaan Settings:** Dukaan ka naam, calling number, WhatsApp number aur pata dashboard se hi change karein.

### 🛍️ 2. Grahak (Customer) Side:
- **Shandar Design:** Festive, Wedding aur Modern look with Plus Jakarta Sans typography.
- **Category Filter:** Men, Women, Ethnic & Festive, Kids Wear.
- **Live Search & Sort:** Kapdo ka naam search karein ya saste se mehenge rate par sort karein.
- **Shopping Cart:** Quantity badhayein ya kam karein, live bill dekhein.
- **Direct WhatsApp Order:** Customer apna naam, phone aur delivery address daalta hai aur "WhatsApp par Order Karein" button dabate hi dukandar ke WhatsApp par saari detail ke saath order send ho jata hai!
